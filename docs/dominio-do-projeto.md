# Domínio do Projeto — BemStock

## Problema

A instituição Lar Bem utiliza diariamente diversos itens essenciais para seu funcionamento, como alimentos, produtos de higiene e produtos de limpeza. O controle desses itens pode ser realizado de forma manual, o que pode gerar dificuldades no acompanhamento das quantidades disponíveis e das movimentações de estoque.

## Contexto

O Lar Bem é uma instituição de acolhimento localizada no Recife, que atende meninas e adolescentes encaminhadas pela justiça devido a medidas protetivas.

Para garantir o funcionamento da instituição, é necessário manter um controle organizado dos recursos utilizados no dia a dia.

## Objetivo do Sistema

O sistema BemStock tem como objetivo organizar e controlar o estoque de alimentos, produtos de higiene e produtos de limpeza da instituição.

O sistema permitirá:

- cadastrar produtos
- registrar entradas de itens
- registrar saídas de itens
- consultar quantidades disponíveis
- identificar produtos com estoque baixo
- acompanhar histórico de movimentações

## Usuários do Sistema

Os principais usuários do sistema serão:

- funcionários administrativos
- responsáveis pelo controle de estoque
- coordenação da instituição

## Itens Controlados

O sistema controlará inicialmente três categorias principais:

- alimentos
- produtos de higiene
- produtos de limpeza

## Operações do Sistema

O sistema permitirá:

- cadastro de produtos
- consulta de estoque
- registro de entrada de produtos
- registro de saída de produtos
- controle de estoque mínimo
- histórico de movimentações
